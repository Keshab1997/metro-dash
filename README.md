# Dog Road Runner 🐶

A tiny, colorful Flutter endless-runner prototype. Dash through a sunny neighborhood, jump over crates, and beat your high score.

## Play

```bash
flutter pub get
flutter run -d chrome
```

For a browser preview on a development host:

```bash
flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8080
```

Tap/click to start and jump. When running in a browser, Space can also activate the tap area. The current art is drawn in Flutter Canvas, so the prototype has no external image/font dependencies yet.
